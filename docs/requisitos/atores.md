Atores  | Descrição
------- | --------
Cidadão | São os usuários finais do sistema, e podem ser definidos como indivíduos que se preocupam com o destino final de seus resíduos.
Administrador do sistema | É o funcionário responsável pela manutenção do software, o tratamento de erros,a veracidade das informações e  atualização dos dados fornecidos ao usuário.
Google Maps API | Um sistema externo cujo objetivo é fornecer dados geográficos e visualização cartográfica.
